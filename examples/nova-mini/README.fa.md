# nova-mini

> 🚀 **تازه‌کارید؟** از [`START-HERE.fa.md`](START-HERE.fa.md) شروع کنید —
> راهنمای قدم‌به‌قدم با فرض اینکه هیچ چیز بلد نیستید.

یک ورکر VLESS-over-WebSocket **با پنل گرافیکی**، کاملاً خوانا و متن‌باز.

**بدون مینیفای، بدون مرحلهٔ بیلد، بدون کد پنهان.** هرچه اینجا می‌خوانید همان
چیزی است که اجرا می‌شود.

---

## چه چیزی دارد

**پنل گرافیکی:**
- ورود با رمز (PBKDF2 با ۲۱۰ هزار تکرار + نشست امضاشده)
- افزودن و حذف کاربر، هرکدام با UUID و لینک اشتراک جدا
- کپی لینک اشتراک با یک کلیک
- تنظیم دامنه‌های دلخواه، پورت و نام اشتراک
- تغییر رمز (همهٔ نشست‌های دیگر باطل می‌شوند)
- محدودیت تلاش ورود (بعد از ۶ تلاش ناموفق، ۱۰ دقیقه قفل)

**لینک اشتراک، همه به‌صورت محلی تولید می‌شوند:**
- `base64` برای v2rayN، Hiddify، Streisand
- `clash` (YAML) برای Clash، mihomo، Stash
- `singbox` (JSON) برای sing-box
- تشخیص خودکار از روی User-Agent کلاینت

**آی‌پی تمیز per-اپراتور:** ⭐ جدید
- تشخیص خودکار اپراتور از روی `request.cf` (همراه اول، ایرانسل، رایتل، شاتل)
- برای هر اپراتور یک لیست آی‌پی جدا
- کانفیگ به آی‌پی تمیز وصل می‌شود ولی SNI/Host روی دامنهٔ شما می‌ماند
- لیست دستی یا آدرس URL خودتان (هیچ اتصالی به سازنده نیست)

**تولید لیست اسکن:** ⭐ جدید
- ساخت آی‌پی کاندیدا از رنج‌های **رسمی کلودفلر**
- دانلود به‌صورت `ip:port` آمادهٔ اسکنر
- الهام‌گرفته از [NovaRadar](https://github.com/IRNova/NovaRadar) (مجوز MIT)

**تونل:**
- VLESS روی WebSocket، دستور TCP
- آدرس IPv4، IPv6 و دامنه
- early-data برای کاهش تأخیر
- fallback به `PROXYIP` **فقط اگر خودتان تنظیم کنید**

## راه‌اندازی

```bash
cd examples/nova-mini
npm install
npx wrangler login
```

### ۱. ساخت فضای KV

```bash
npx wrangler kv namespace create KV
```

شناسه‌ای که می‌دهد را در `wrangler.jsonc` جای `PUT-YOUR-KV-NAMESPACE-ID-HERE` بگذارید.

### ۲. نام ورکر

در `wrangler.jsonc` مقدار `name` را به چیزی غیرقابل‌حدس تغییر دهید
(`vpn`، `proxy`، `nova` نگذارید).

### ۳. توکن ادعا (مهم)

```bash
npx wrangler secret put CLAIM_TOKEN     # با: openssl rand -hex 16
```

بدون این، هرکسی زودتر از شما `/admin` را باز کند می‌تواند رمز بگذارد و
صاحب پنل شود.

### ۴. تست و دیپلوی

```bash
npm run check      # syntax + ۲۹ تست + dry-run
npm run deploy
```

### ۵. اولین ورود

```
https://<worker>.workers.dev/admin/setup?claim=<CLAIM_TOKEN>
```

رمز ادمین بسازید (حداقل ۱۰ کاراکتر). بعد از آن پنل در `/admin` است.

### ۶. ساخت کاربر

در پنل یک اسم بزنید و **Add**. بعد **Copy link** را بزنید و لینک را در
کلاینت (v2rayN، Hiddify، Clash) وارد کنید. تمام.

## متغیرها

| نام | نوع | کاربرد |
|---|---|---|
| `KV` | بایندینگ | **ضروری.** ذخیرهٔ کاربران، تنظیمات و رمز |
| `CLAIM_TOKEN` | secret | توصیه‌شده. محافظت از اولین راه‌اندازی |
| `PROXYIP` | secret | اختیاری. نود پشتیبان وقتی اتصال مستقیم بسته است |
| `UUID` | secret | اختیاری. حالت تک‌کاربره بدون پنل |
| `MAX_USERS` | var | سقف کاربر (پیش‌فرض ۱۰) |

## چه چیزی ندارد

صادقانه، اینها را ننوشتم:

- سهمیهٔ حجمی، انقضا، محدودیت سرعت
- آمار مصرف و لاگ ترافیک
- ربات تلگرام
- **UDP** و در نتیجه تماس تصویری (محدودیت خود Cloudflare Workers است)
- WARP، زنجیرهٔ پراکسی، DoH، مسیریابی کشوری
- **اسکن واقعی آی‌پی داخل ورکر.** کلودفلر اتصال TCP خام به آی‌پی را مسدود
  می‌کند (سندباکس SSRF)، پس اسکن باید روی کامپیوتر خودتان انجام شود. پنل
  لیست کاندیدا می‌سازد؛ تستش با ابزاری مثل NovaRadar یا هر اسکنر دیگر است.

اگر این‌ها را لازم دارید، نسخهٔ پچ‌شدهٔ Nova-Proxy در ریشهٔ مخزن گزینهٔ
عملی‌تری است.

## چرا این امن‌تر است

سه موردی که در ممیزی Nova-Proxy پیدا شد و **اینجا ساختاراً وجود ندارند**:

1. **رلهٔ مخفی شخص ثالث** — آنجا وقتی PROXYIP خالی بود ترافیک به دامنه‌ای
   می‌رفت که اسمش در زمان اجرا ساخته می‌شد تا در جست‌وجو پیدا نشود. اینجا
   اگر PROXYIP نباشد، اتصال با خطای صریح رد می‌شود.
2. **تلمتری نصب** — هیچ درخواست خروجی‌ای به‌جز مقصد خود کاربر وجود ندارد.
3. **به‌روزرسانی خودکار از مخزن سازنده** — کد فقط با `npm run deploy` خودتان
   عوض می‌شود.

ضمناً مبدل اشتراک محلی است، پس **هیچ سرور شخص ثالثی کانفیگ‌های شما را نمی‌بیند**
(نسخهٔ اصلی به `SUBAPI.cmliussss.net` می‌فرستاد).

## محدودیت‌هایی که باید بدانید

- **زیر بار واقعی تست نشده.** ۲۹ تست منطق را پوشش می‌دهند و کل جریان پنل را
  با درخواست HTTP واقعی روی `wrangler dev` تست کردم (نصب، ورود، افزودن
  کاربر، هر سه فرمت اشتراک، تغییر رمز، محدودیت ورود). ولی یک کلاینت واقعی
  را به ورکر واقعی وصل نکردم و ترافیک عبور ندادم. قبل از تکیه‌کردن، خودتان
  با v2rayN یا Hiddify تست کنید.
- **UDP ندارد**، پس تماس تصویری کار نمی‌کند.
- **بدون مبهم‌سازی.** اگر شبکه‌ای الگوی VLESS-over-WS را فینگرپرینت کند،
  این هم شناسایی می‌شود. دامنهٔ شخصی کمک می‌کند.
- **KV سازگاری نهایی دارد** — تغییر تنظیمات ممکن است چند ثانیه طول بکشد.
