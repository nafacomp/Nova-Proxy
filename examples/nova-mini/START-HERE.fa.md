# nova-mini — راهنمای صفر تا صد

این راهنما فرض می‌کند **هیچ چیز بلد نیستید**. هر دستور را دقیقاً همان‌طور که
نوشته شده کپی کنید.

**زمان:** حدود ۲۰ دقیقه · **هزینه:** صفر (پلن رایگان کلودفلر)

---

## قبل از شروع: قرار است چه کار کنیم؟

خیلی ساده بگویم:

1. یک برنامهٔ کوچک روی سرورهای **کلودفلر** آپلود می‌کنیم (به این می‌گویند «ورکر»).
2. این برنامه یک **آدرس اینترنتی** به شما می‌دهد، مثل `https://چیزی.workers.dev`.
3. آن آدرس دو کار می‌کند: یک **پنل مدیریت** دارد که با مرورگر بازش می‌کنید، و
   یک **تونل** که موبایل و لپ‌تاپ شما از آن رد می‌شوند.
4. در پنل «کاربر» می‌سازید. هر کاربر یک **لینک اشتراک** می‌گیرد که در برنامهٔ
   VPN موبایل وارد می‌کنید.

نه سروری می‌خرید، نه چیزی نصب می‌کنید روی سرور. همه‌چیز روی کلودفلر است.

---

## قدم ۰ — دو چیزی که لازم دارید

### الف) حساب کلودفلر (رایگان)

به https://dash.cloudflare.com/sign-up بروید و ثبت‌نام کنید.
ایمیل و رمز کافی است، کارت بانکی نمی‌خواهد.

### ب) نصب Node.js

به https://nodejs.org بروید و نسخهٔ **LTS** را دانلود و نصب کنید.

بعد از نصب، **ترمینال** را باز کنید:

- **ویندوز:** دکمهٔ ویندوز را بزنید، بنویسید `PowerShell`، بازش کنید
- **مک:** `Command + Space`، بنویسید `Terminal`
- **لینوکس:** `Ctrl + Alt + T`

این را تایپ کنید و Enter بزنید:

```bash
node --version
```

اگر چیزی مثل `v22.14.0` دیدید یعنی درست نصب شده. اگر خطا داد، Node.js نصب نشده.

> **ترمینال چیست؟** یک پنجرهٔ سیاه که در آن دستور تایپ می‌کنید. نترسید،
> فقط باید دستورهای این راهنما را کپی و Enter کنید.

---

## قدم ۱ — گرفتن فایل‌ها

این سه دستور را **یکی‌یکی** بزنید (بعد از هرکدام Enter):

```bash
git clone https://github.com/nafacomp/Nova-Proxy.git
cd Nova-Proxy/examples/nova-mini
npm install
```

> `npm install` ممکن است یکی دو دقیقه طول بکشد و کلی متن نشان دهد. طبیعی است.
> اگر `git` را نداشتید، از https://git-scm.com نصبش کنید.

**مهم:** از این به بعد همهٔ دستورها باید در همین پوشه زده شوند. اگر ترمینال را
بستید و دوباره باز کردید، اول این را بزنید:

```bash
cd Nova-Proxy/examples/nova-mini
```

---

## قدم ۲ — وصل شدن به حساب کلودفلر

```bash
npx wrangler login
```

مرورگر خودش باز می‌شود و می‌پرسد اجازه می‌دهید؟ روی **Allow** بزنید.
بعد به ترمینال برگردید.

برای مطمئن شدن:

```bash
npx wrangler whoami
```

باید ایمیل حساب کلودفلرتان را نشان بدهد.

---

## قدم ۳ — ساخت انبار داده (خودکار)

پنل باید کاربران و رمز شما را یک جایی ذخیره کند. این دستور خودش می‌سازدش:

```bash
npm run setup
```

خروجی موفق:

```
✓ Logged in to Cloudflare as you@example.com
✓ KV ready  (a1b2c3d4e5f6...)
✓ wrangler.jsonc updated
```

> اگر دوباره اجرایش کنید مشکلی نیست، چیزی خراب نمی‌شود.

---

## قدم ۴ — انتخاب یک اسم

فایل `wrangler.jsonc` را با هر ویرایشگر متنی باز کنید (Notepad هم کافی است).

خط اول را پیدا کنید:

```jsonc
"name": "my-tunnel",
```

`my-tunnel` را به یک اسم **غیرقابل‌حدس** تغییر دهید، مثلاً:

```jsonc
"name": "k7-edge-2291",
```

> ⚠️ **اسم‌هایی مثل `vpn`، `proxy`، `nova`، `filter` نگذارید.** این اسم‌ها
> اسکن و مسدود می‌شوند. یک ترکیب بی‌معنی از حرف و عدد بهترین است.

این اسم در آدرس نهایی شما می‌آید: `https://k7-edge-2291.چیزی.workers.dev`

فایل را ذخیره کنید.

---

## قدم ۵ — ساخت یک رمز محافظ (خیلی مهم)

وقتی پنل تازه بالا می‌آید، هنوز رمزی ندارد. **هرکسی زودتر از شما آدرسش را پیدا
کند، می‌تواند رمز بگذارد و صاحب پنل شود.** این قدم آن پنجره را می‌بندد.

اول یک رشتهٔ تصادفی بسازید:

```bash
node -e "console.log(require('crypto').randomBytes(16).toString('hex'))"
```

چیزی مثل این می‌دهد:

```
7f3a9c2e5b8d1046af62e0c94d7b3518
```

**این را کپی کنید و جایی نگه دارید** (یادداشت گوشی، فایل متنی، هرجا).

حالا:

```bash
npx wrangler secret put CLAIM_TOKEN
```

می‌پرسد مقدار را وارد کنید. آن رشته را **paste** کنید و Enter بزنید.

> موقع paste کردن ممکن است چیزی روی صفحه نبینید. طبیعی است، برای امنیت است.
> فقط paste کنید و Enter بزنید.

---

## قدم ۶ — تست قبل از آپلود

```bash
npm run check
```

این ۲۹ تست را اجرا می‌کند. اگر آخرش `# fail 0` دیدید، همه‌چیز سالم است.
هنوز چیزی روی اینترنت نرفته.

---

## قدم ۷ — آپلود

```bash
npm run deploy
```

آخر خروجی یک آدرس می‌بینید، چیزی شبیه:

```
https://k7-edge-2291.your-name.workers.dev
```

**این آدرس را کپی کنید.** این آدرس سرویس شماست.

---

## قدم ۸ — اولین ورود به پنل

در مرورگر این آدرس را باز کنید — به‌جای دو قسمت داخل `<>` مقدار خودتان را بگذارید:

```
https://<آدرس-شما>/admin/setup?claim=<رشته-ای-که-در-قدم-۵-ساختید>
```

مثال واقعی:

```
https://k7-edge-2291.your-name.workers.dev/admin/setup?claim=7f3a9c2e5b8d1046af62e0c94d7b3518
```

یک صفحه می‌بینید که می‌گوید **Create your admin password**.

رمز پنل را بسازید (حداقل ۱۰ کاراکتر). **این رمز را جایی یادداشت کنید.**

بعد از این، پنل شما اینجاست:

```
https://<آدرس-شما>/admin
```

---

## قدم ۹ — ساخت اولین کاربر

در پنل:

1. در کادر **Name** یک اسم بنویسید (مثلاً `گوشی-من`)
2. دکمهٔ **Add** را بزنید
3. در جدول، کنار اسم، دکمهٔ **Copy link** را بزنید

حالا یک لینک در کلیپ‌بورد شماست، چیزی شبیه:

```
https://k7-edge-2291.your-name.workers.dev/sub/a1b65c449652ac8d553d3f60bc737b58
```

> ⚠️ **این لینک مثل رمز عبور است.** به کسی ندهید. هرکسی داشته باشد می‌تواند
> از سرویس شما استفاده کند.

---

## قدم ۱۰ — وصل شدن با موبایل یا کامپیوتر

### اندروید

1. برنامهٔ **v2rayNG** یا **Hiddify** را نصب کنید
2. دکمهٔ `+` را بزنید
3. گزینهٔ **Import from clipboard** یا **افزودن از کلیپ‌بورد** را بزنید
   (لینک را از قبل کپی کرده‌اید)
4. کانفیگ ظاهر می‌شود، رویش بزنید و دکمهٔ اتصال را بزنید

### آیفون

1. برنامهٔ **Streisand** یا **Shadowrocket** را نصب کنید
2. `+` بزنید و **Subscribe** یا **Import from clipboard** را انتخاب کنید
3. لینک را paste کنید

### ویندوز / مک

1. برنامهٔ **v2rayN** (ویندوز) یا **V2Box** (مک) را نصب کنید
2. `Subscription > Add` را بزنید و لینک را paste کنید
3. `Update subscription` بزنید

**تمام.** حالا باید وصل شوید.

---

## بعد از نصب: کارهایی که حتماً باید بکنید

اینها اختیاری به‌نظر می‌رسند ولی **دقیقاً همان چیزهایی هستند که جلوی بن‌شدن
را می‌گیرند**:

### ۱. دامنهٔ شخصی وصل کنید (مهم‌ترین)

آدرس `workers.dev` در ایران و خیلی کشورها **از قبل مسدود است**. با دامنهٔ
شخصی، سرویس شما خیلی پایدارتر می‌شود.

یک دامنهٔ ارزان بخرید، به کلودفلر اضافه‌اش کنید، بعد:
`Workers & Pages > ورکر شما > Settings > Domains & Routes > Add`

بعد در پنل، در بخش **Settings**، آن دامنه را در کادر **Hosts** بنویسید و
**Save** بزنید.

### ۲. لینک اشتراک را پخش نکنید

هر لینک یک اعتبارنامه است. **علت بن‌شدن قبلی شما همین بود، نه کد.**
اگر بین ده‌ها نفر پخش شود، ترافیک بالا می‌رود و کلودفلر می‌بندد.

### ۳. رمز پنل را قوی بگذارید

پنل بعد از ۶ تلاش ناموفق ۱۰ دقیقه قفل می‌شود، ولی رمز قوی همیشه بهتر است.

## عیب‌یابی

### وصل نمی‌شوم

اول مطمئن شوید خود ورکر بالاست. در مرورگر باز کنید:

```
https://<آدرس-شما>/admin
```

- **صفحهٔ ورود آمد** → ورکر سالم است، مشکل از تنظیمات کلاینت است.
  لینک را دوباره کپی کنید و در برنامه به‌روزرسانی (Update) بزنید.
- **صفحه نیامد** → ورکر مشکل دارد. `npm run deploy` را دوباره بزنید.

### خطای `PUT-YOUR-KV-NAMESPACE-ID-HERE`

قدم ۳ را انجام نداده‌اید. `npm run setup` را بزنید.

### پنل می‌گوید Wrong password

رمز اشتباه است. اگر فراموش کرده‌اید، بخش بعدی را ببینید.

### رمز پنل را فراموش کردم

در ترمینال، فقط رمز ذخیره‌شده را پاک کنید:

```bash
npx wrangler kv key delete --binding KV "admin.json" --remote
```

می‌پرسد مطمئنید؟ تأیید کنید. بعد دوباره به این آدرس بروید و رمز جدید بسازید:

```
https://<آدرس-شما>/admin/setup?claim=<توکن-قدم-۵>
```

> ✅ **کاربرانی که ساخته‌اید پاک نمی‌شوند**، فقط رمز پنل ریست می‌شود.
> این را واقعاً تست کردم: بعد از ریست، هر ۵ کاربر و لینک‌هایشان سالم ماندند.

### بعد از ۶ بار تلاش، قفل شدم

۱۰ دقیقه صبر کنید. این محافظت در برابر حدس زدن رمز است.

### می‌خواهم ببینم چه اتفاقی می‌افتد

```bash
npx wrangler tail
```

این لاگ زنده را نشان می‌دهد. برای خروج `Ctrl + C`.

### تماس تصویری (واتساپ، فیس‌تایم) کار نمی‌کند

این کار نمی‌کند و **قابل رفع نیست**. تماس تصویری به UDP نیاز دارد و
Cloudflare Workers اصلاً UDP ندارد. محدودیت پلتفرم است، نه باگ.

## کارهای روزمره

### اضافه کردن دستگاه جدید

در پنل یک کاربر جدید بسازید و لینکش را در آن دستگاه وارد کنید.
**برای هر دستگاه یک کاربر جدا بسازید** تا اگر یکی لو رفت فقط همان را حذف کنید.

### حذف یک دستگاه

در پنل، کنار اسم کاربر، دکمهٔ **Delete** را بزنید.
لینکش بلافاصله از کار می‌افتد.

### تغییر رمز پنل

در پنل، بخش **Change password**. بعد از تغییر، همهٔ نشست‌های دیگر
(مثلاً مرورگر دیگری که باز مانده) خودبه‌خود خارج می‌شوند.

### به‌روزرسانی کد

```bash
git pull
npm install
npm run deploy
```

## محدودیت‌هایی که باید بدانید

صادقانه:

- **تماس تصویری کار نمی‌کند** (UDP ندارد — محدودیت خود کلودفلر)
- **سهمیهٔ حجمی و انقضا ندارد** — نمی‌توانید برای کاربر محدودیت حجم بگذارید
- **آمار مصرف ندارد** — نمی‌بینید چقدر مصرف شده
- **ربات تلگرام ندارد**
- **با کلاینت واقعی زیر بار تست نشده** — منطق و کل جریان پنل با درخواست واقعی
  تست شده، ولی عبور ترافیک واقعی را باید خودتان امتحان کنید

اگر سهمیه و آمار می‌خواهید، نسخهٔ کامل Nova در ریشهٔ مخزن هست
(راهنمایش: `../../START-HERE.fa.md`) — ولی آن فایل مینیفای است و
قابل بررسی کامل نیست. nova-mini کل کدش ۶ فایل خوانا است.

## خلاصهٔ همهٔ دستورها

اگر عجله دارید:

```bash
git clone https://github.com/nafacomp/Nova-Proxy.git
cd Nova-Proxy/examples/nova-mini
npm install
npx wrangler login
npm run setup
# wrangler.jsonc را باز کنید و "name" را عوض کنید
node -e "console.log(require('crypto').randomBytes(16).toString('hex'))"
npx wrangler secret put CLAIM_TOKEN
npm run check
npm run deploy
# بعد: https://<آدرس>/admin/setup?claim=<توکن>
```
